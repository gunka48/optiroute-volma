OptiRoute ВОЛМА — Цифровая логистика

Интеллектуальная система управления цепочками поставок для **ООО «УК «ВОЛМА»** (Хакатон «ТЕХНОВЕКтор 20.26»).

Сервис строит оптимальные автомобильные маршруты с учетом категории автодорог, типа груза (сырье / хрупкий гипсокартон) и нормативных регламентов режима труда водителя (ЕСТР / Минтранс РФ).

---

Структура проекта

хакатон/
├── install.bat          # 1. Автоматическая установка библиотек (запустить один раз)
├── run.bat              # 2. Запуск сервера и открытие браузера
├── main.py              # Backend (FastAPI, OSRM API) + Frontend (Leaflet.js)
├── requirements.txt     # Зависимости Python
└── README.md            # Документация

---

Быстрый запуск
Установка (один раз):
Запустите файл install.bat (создаст окружение venv и скачает библиотеки).

Запуск проекта:
Запустите файл run.bat. Сервер стартует, и через 2 секунды автоматически откроется браузер по адресу: http://127.0.0.1:8000.

Сценарий для демонстрации
1. Перевозка хрупкой продукции (Гипсокартон ГКЛ)
В конструкторе слева выберите: ВОЛМА-Волгоград ➔ ВОЛМА-Воскресенск (Москва) | ХРУПКИЙ: Гипсокартон.
Оставьте галочку «Учет качества трасс» ВКЛЮЧЕННОЙ и нажмите «Рассчитать маршрут»
Результат: На карте построится зеленая федеральная трасса (М-4 «Дон»). Риск боя равен всего 1.2%.

2. Сравнение с неоптимальным маршрутом (Демонстрация экономии)
На том же маршруте СНИМИТЕ галочку «Учет качества трасс» и нажмите «Рассчитать маршрут».
Результат: Линия станет красной (маршрут сместился на региональные срезки). Система зафиксирует критический бой 13.4% и покажет суммы прямых убытков от повреждения товара.

3. Расчет нормативного времени труда водителя (Приказ Минтранса РФ № 424)
В сводке рейса автоматически рассчитываются:

Чистое время езды (из расчета средней скорости фуры 75 км/ч).
Технические перерывы (по 45 минут каждые 4.5 часа за рулем).
Межсменный отдых / ночевки (по 11 часов после каждых 9 часов руления).

4. Обзор всей сети ВОЛМА
Нажмите синюю кнопку «Отобразить все объекты ВОЛМА» — карта масштабируется и покажет расположение всех 4 карьеров, 9 заводов и Волгоградского хаба.
